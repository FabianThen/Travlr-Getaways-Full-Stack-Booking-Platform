# Travlr Getaways — Full-Stack MEAN Travel Booking Platform

A full-stack travel-booking application built on MongoDB, Express, Angular, and Node.js.

## Architecture

- `app_api/` — REST API (Express + Mongoose), JWT authentication via Passport
- `app_admin/` — Angular admin single-page application (trip management, login)
- `app_server/` — Handlebars-rendered public-facing site
- `data/` — seed data

## Tech stack

MongoDB, Mongoose, Express, Node.js, Angular, TypeScript, Passport, JWT
